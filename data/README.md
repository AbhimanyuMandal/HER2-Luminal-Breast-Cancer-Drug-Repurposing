# Data

The raw and processed datasets are not included in this repository because of
their large file size.

The project uses publicly available datasets from GEO and the Broad LINCS
Connectivity Map.

## Datasets

### GSE176078

Wu et al. breast cancer single-cell RNA-seq dataset.

GEO accession: GSE176078

### GSE113196

Normal breast tissue single-cell RNA-seq dataset.

GEO accession: GSE113196

### GSE92742 / LINCS

Broad LINCS Level 5 perturbational signatures used for transcriptomic
connectivity-based drug repurposing.

GEO accession: GSE92742

The large LINCS GCTX matrix is not included in this repository.
